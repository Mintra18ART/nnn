© 2026 ระบบสารสนเทศเพื่อการเฝ้าระวังทางสาธารณสุข (Public Health Surveillance System)

พัฒนาสำหรับนักวิชาการสาธารณสุข และเจ้าหน้าที่ผู้ปฏิบัติงานในพื้นที่

ขั้นตอนการนำ Web App ขึ้นใช้งานบน GitHub Pages

เผยแพร่ Dashboard ให้ใช้งานออนไลน์ได้ฟรีตลอด 24 ชั่วโมง

การเตรียมข้อมูล Google Sheets สำหรับ Realtime Data

ไปที่ไฟล์ Google Sheets ของคุณ → เลือก ไฟล์ (File) → แชร์ (Share) → เผยแพร่ไปยังเว็บ (Publish to Web) → เปลี่ยนจาก เว็บเพจ เป็น ค่าที่คั่นด้วยเครื่องหมายจุลภาค (.csv) แล้วคัดลอกลิงก์มาใช้

  1. สร้าง Repository บน GitHub

    เข้าเว็บ GitHub.com ล็อกอิน แล้วกดปุ่ม "New" เพื่อสร้าง Repository ใหม่ ตั้งชื่อเช่น health-dashboard และเลือกเป็น Public

  2. อัปโหลดไฟล์ HTML

    บันทึกโค้ดหน้านี้เป็นไฟล์ชื่อ index.html แล้วกดอัปโหลดขึ้นไปยัง Repository ที่สร้างไว้ (Add file → Upload files)

  3. เปิดใช้งาน GitHub Pages

    ไปที่แท็บ Settings → เลือกเมนูแถบข้าง Pages → ในส่วน Branch เลือก main หรือ master และเลือกโฟลเดอร์เป็น /(root) แล้วกด Save

  4. เข้าใช้งาน Dashboard

    รอระบบ Build ประมาณ 1-2 นาที คุณจะได้ลิงก์เว็บไซต์พร้อมแชร์ใช้งาน เช่น:
    https://your-username.github.io/health-dashboard/
